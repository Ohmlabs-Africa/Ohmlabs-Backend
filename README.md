# OHM Labs

The backend API for the OHM Labs website. It supports the site's contact and service forms, account access, and collaborative client projects.

## Features

- Contact, proposal, font submission, and booking forms
- Secure admin and client accounts, with admin approval for new client registrations
- Password recovery and email notifications
- Admin dashboard statistics and submission management
- Shared projects, tasks, support tickets, and project chat
- Protected API access with role-based permissions
